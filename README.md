# QUT Communication Assignment Structure

This repository records the requirements and writing structure for the QUT005 communication assignment.

## Files

- [assignment-requirements.md](assignment-requirements.md): extracted and organised assignment requirements, including word counts, source requirements, topic limits, and submission checklist.
- [essay-structure.md](essay-structure.md): a practical essay structure you can use to plan and draft the three assignment parts.

## Assignment At A Glance

- Part A: interpersonal communication scene analysis, 500 words +/-10%.
- Part B: visual stereotype advertisement analysis and ethical redesign, 500 words +/-10%.
- Part C: professional body social media representation analysis, 500 words +/-10%.
- References: at least 9 total, with at least 3 for each part.
- Submission: PDF named `FIRSTNAME_LASTNAME_STUDENTNUMBER.pdf`.
